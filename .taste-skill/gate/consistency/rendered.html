Event Loop Architecture: Microtask vs Macrotask

Khám phá cơ chế điều phối luồng thực thi trong JavaScript runtime: thứ tự ưu tiên Microtask Queue, Task Queue và chu kỳ Render.

Mô hình chu trình Event Loop (V8 Runtime)
Single-threaded Event Model
1. Call Stack

Thực thi đồng bộ LIFO cho tới khi stack rỗng hoàn toàn.

2. Microtasks (VIP)

Dọn sạch 100% Promise, await trước khi chuyển bước.

3. Render Phase

Tính toán Style, Layout, Paint và rAF mỗi 16.6ms (60fps).

4. Macrotasks

Lấy duy nhất 1 callback timer/IO mỗi vòng lặp tick.

!

Quy tắc vàng

Sau mỗi macrotask, event loop sẽ làm rỗng toàn bộ hàng đợi microtask trước khi chạy macrotask tiếp theo. Vì vậy Promise.then() luôn chạy trước setTimeout(0).
